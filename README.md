## Quick Start

## LINUX USER
```bash
git clone https://github.com/DamiTheClown/arp-poisoner.git
cd arp-poisoner

./setup.sh
```

## OR

```bash
# Clone the repository
git clone https://github.com/DamiTheClown/arp-poisoner.git
cd arp-poisoner

# Make your own venv
python3 -m venv venv

---
# Activate your venv

#LINUX
source venv/bin/activate

#WINDOWS
.venv\bin\activate.ps1
---

# Install Scapy library and Rich library
pip install scapy rich

# Start __main__.py
python3 __main__.py
```
